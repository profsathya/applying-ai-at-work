## Course Purpose

Help team members use this repository safely through the Codex app or Codex in an IDE. By the end, participants can orient to the repo, configure local dependencies, ask Codex for scoped work, review generated files, verify Canvas-ready outputs, and decide when a new skill, agent, or deterministic script is justified.

## Audience And Situation

The course is for technical and non-technical team members who need to operate this repo without a live walkthrough. Participants may be course authors, reviewers, program staff, or maintainers. They should not need prior agentic workflow experience.

## Course Arc

The course uses four self-paced modules: orientation, setup and first run, building with Codex and local agents, then verification and extension.

## Assessment Strategy

Each module includes practical pages, a formative check, and an applied task. The final applied task asks participants to inspect, scope, and verify a repo workflow without publishing to Canvas.

## Constraints

No due dates are included. Generated artifacts are staged with `publish: false` until a human reviews them. The main learner workflow is Codex app or IDE, not Codex CLI. Terminal commands appear only as repository setup, validation, or technical appendix steps.
