# Where work lives

## The rule

Structured work done in one sitting lives on a walkthrough page. Work edited across several activities lives in a document. A plain Canvas box holds only short, single-step prose, and it is the submission surface for everything.

Two working surfaces:

- **A walkthrough page** (Jeremy's `presentation: walkthrough`, 22 September). A Canvas page that is itself a table, with guidance beside each field, and that generates a Word file at the end. Right for a one-sitting activity with structure: a table, repeated parts, columns filled in passes. The Word file is the learner's to keep, open in Word or Google Docs, and edit later, so it also covers the "bring it back" case. The page must tell them to download it before they leave; the page keeps a draft only in that browser.
- **A document** (a Google Doc template the learner copies once). Right for anything edited across activities from the start, or that lives across sprints: the Problem Frame.

And the box:

- **A plain Canvas box** (guided assignment, `reading` or `compact`). Right as a working surface only for short single-step prose: a verdict, a reflection, a check, a transcript paste. Nobody develops a table or a seven-part frame in a box. Sprint 1 shows it: First frames has boxes, and the frames were written in the Candidate Log and pasted. Boxes with structured work behind them are paste surfaces, and a paste surface needs a document or a walkthrough export behind it.

## Sprint 1, read against the rule

| Activity | Written | Reads as | Note |
|---|---|---|---|
| Brainstorm your list (Part A) | one sitting, a list | box, or Jeremy's interleaved version | the one Sprint 1 activity simple enough for a box |
| Get underneath three to five (Part B) | one sitting, a table | walkthrough | four columns, three to five rows |
| First frames (Part C) | one sitting, structured | walkthrough | seven parts per frame, three to five frames |
| Dojo Lab: test, widen, choose | one sitting | box (transcript) | reads Part C, does not edit it |
| Problem Frame (Part D) | one sitting, then edited every sprint | document | the one document the course needs |

Parts A to D of the Candidate Log correspond one to one to these activities, each written on its own page in one sitting. The only cross-activity use is Part C's draft frames, which are copied twice (into the Dojo Lab, and the runner-up's frame in Sprint 2 if the first problem fails), never edited. A copy from an earlier Canvas submission covers that. So if Get underneath and First frames become walkthroughs, the Candidate Log document can go; their Word exports are what the learner keeps. The Problem Frame stays a document because every sprint edits it.

## Sprint 2, read against the rule

| Activity | Written | Reads as | Built today as |
|---|---|---|---|
| Dig into your assumptions | one sitting, a table plus a check | walkthrough | reading with two boxes (fallback), plus the staged walkthrough |
| Dojo Lab: test your assumptions | one sitting | box (transcript) | transcript |
| Which assumptions, and your check | paste | box | reading, two boxes |
| What solutions already exist | started in one sitting, then edited across three activities in one week | walkthrough, whose Word export is the document | reading with one box (fallback), plus the staged walkthrough |
| Dojo Lab: explore what already exists | edits the table row by row | box (transcript) | transcript |
| What exists, and what it means | paste | box | reading, five boxes |
| Problem Frame: is it worth pursuing? | paste from the Problem Frame document | box | reading, three boxes |

What already exists is the case that shows the walkthrough export doing the document's job: the learner fills the table on the page, downloads the Word file with the table and an empty "After the Dojo Lab" section, and that file is what they edit through the Dojo Lab and paste from in the write-up and the Problem Frame item. No separate template.

The reading versions built today are fallbacks, and a fallback box needs a document behind it. What already exists has one (`what-already-exists-template.md`); the Assumptions walk does not. If the walkthroughs cannot be released before 5 October, an Assumptions walk Google Doc template is made and both reading pages link their document; if they can, the reading versions never go live and no templates are needed.
