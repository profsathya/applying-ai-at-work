# Where work lives

## The rule

Work that is written in one sitting lives in a Canvas box. Work that is edited across several activities needs a document to live in. The box is always the submission surface; the question is only where the learner works.

Three places work can live:

- **A Canvas box** (guided assignment, `reading` or `compact` presentation). The learner writes in the box, copies it, submits it. Right for anything done in one sitting.
- **A document** (a Google Doc template the learner copies once). Right for anything the learner edits across activities, keeps open beside a chat, or brings back weeks later.
- **A walkthrough page** (Jeremy's `presentation: walkthrough`, 22 September). A Canvas page that is itself a table, with guidance beside each field, and that exports a Word file at the end. Right for a one-sitting activity with many fields, and it gives the learner a file to keep, which covers the "bring it back" case without a Google Doc.

| Get underneath three to five (Part B) | one sitting | box or walkthrough | a four-column table; walkthrough suits it |
| First frames (Part C) | one sitting | box or walkthrough | seven parts per frame, three to five frames; walkthrough suits it |
| Dojo Lab: test, widen, choose | one sitting | box (transcript) | reads Part C, does not edit it |
| Problem Frame (Part D) | one sitting, then edited every sprint | document | the one document the course needs |

Parts A to D of the Candidate Log correspond one to one to these activities, each written on its own page in one sitting. The only cross-activity use is Part C's draft frames, which are copied twice (into the Dojo Lab, and the runner-up's frame in Sprint 2 if the first problem fails), never edited. A copy from an earlier Canvas submission covers that. So if Sprint 1's activities convert to boxes, the Candidate Log document can go. The Problem Frame stays a document because every sprint edits it.

The one mismatch is What already exists. As built, its box is the working surface, and there is no document for the table to live in between the activity, the Dojo Lab, the write-up, and 3c. Proposed fix, one line: link the What already exists Google Doc template (`what-already-exists-template.md`) from the page as the place to work, and make the box "paste your table." When Jeremy releases the walkthrough replacement, its Word export becomes the document and the link goes.
