# Welcome and Orientation

Start here before Sprint 1. This short module orients you to what the course is, how it is paced, how to pick the goal you will carry for ten weeks, and how you will use AI as a thinking partner. It also holds the Tutorials and Resources hub you will return to whenever you need a how-to guide, the glossary, or troubleshooting.

You do not submit anything from this module. Read the Welcome page first, then set up your Dojo access from the Tutorials and Resources page so you are ready when Sprint 1 begins.
