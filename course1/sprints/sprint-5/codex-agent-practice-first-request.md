# Codex Agent Practice: First Request

Write a small plain-English request you could give Codex for a course-building task in this repo. The request should be realistic and low stakes. You are practicing how to scope the work before any files are written.

## What to submit

Type your response directly into the text entry box. Include three parts.

1. **The request.** Write the exact message you would give Codex. Name the course, sprint, artifact type, audience, and purpose.
2. **The guardrails.** State what Codex should not do. Include at least two constraints, such as no due dates, no file uploads, no edits outside a named folder, no Canvas push, or no changes to manifests.
3. **Your review plan.** Name two or three things you would check in the generated Markdown before approving any next step.

Keep this short. A strong submission is specific enough that another person could tell whether Codex followed the request.
