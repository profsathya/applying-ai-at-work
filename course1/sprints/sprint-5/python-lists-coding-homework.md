# Python Lists Coding Homework

## Scenario

You are helping organize a beginner coding practice group. The group wants a simple program that stores the names of practice topics, updates the list, and prints a clean summary.

## Requirements

Create a Python file named `python_lists_homework.py`.

Your program must:

  1. Create a list named `topics` with at least four beginner Python topics.
  2. Print the original list.
  3. Add one new topic with `.append()`.
  4. Change one existing topic by using its index.
  5. Remove one topic with either `.remove()` or `.pop()`.
  6. Use a `for` loop to print each final topic on its own line.
  7. Print the total number of topics with `len()`.
  8. Include at least three comments explaining what your code is doing.
