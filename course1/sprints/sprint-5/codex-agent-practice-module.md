# Practice: Using Codex Agents

This short practice module introduces the plain-English workflow for using Codex agents in this repo. It is designed for instructors and course builders who want to make small, controlled course updates without learning the full technical stack.

The goal is not to automate your judgment. The goal is to give clear instructions, review the Markdown that Codex drafts, validate the files locally, and stop before any Canvas push unless a human explicitly approves it.

## What you will practice

- Asking Codex for a small course-building task in plain English.
- Checking whether the generated Markdown follows the repo rules.
- Running local validation before any Canvas write.
- Describing what you would approve, revise, or reject before publishing.

By the end of this module, you should be able to make a small request to Codex and understand the review steps that keep the workflow controlled.
