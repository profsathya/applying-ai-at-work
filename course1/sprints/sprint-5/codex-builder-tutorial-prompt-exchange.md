# Prompt Exchange: Ask Codex For A Course Or Module Build

Post one prompt you would give Codex to draft a course, a Canvas module, or a single course artifact.

Your prompt should include:

- The course and sprint.
- The source context or tutorial section Codex should use.
- Whether you want a whole course, one module, or one artifact.
- The module or artifact list you want.
- The coworker or participant audience.
- Required artifact types, if any.
- Any points or submission types that matter.
- A clear boundary such as `generate Markdown only`, `validate the files`, or `stop before Canvas`.

## Example

```text
Draft course2 sprint 1 from context/module-specs/course2-sprint-1-stakeholder-framing.md. The audience is working professionals. Include a module header, briefing page, two assignments, a 5-question quiz, and a peer discussion. Generate Markdown only, validate the files, and stop before Canvas.
```

After you post, reply to one peer. Suggest one way to make their prompt clearer, safer, or easier for Codex to complete.
