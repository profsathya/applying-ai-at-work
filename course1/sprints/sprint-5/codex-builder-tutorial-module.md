# Using This Codex Course Builder

This module teaches coworkers how to use the Codex course-building tutorial in this repo to draft a course or a Canvas module.

The goal is practical: you should be able to open Codex from the repo, describe a course or module build in plain English, review the local Markdown draft, validate the files, and decide whether the work is ready for Canvas.

You do not need to know the internal scripts before you begin. You do need to name the target course, the sprint or module, the artifact types, the audience, the source material, and whether Canvas publishing is allowed.

If this repo is new to you, treat the course files as the editable draft and Canvas as the published copy. Your first goal is not to publish. Your first goal is to get a clear local draft that another coworker can inspect.

## What you will learn

- How to start a Codex session from the repo.
- How to choose between a whole-course request and a one-module request.
- How to describe a course or module with enough context for Codex to draft it.
- How Codex chooses the internal workflow from your request.
- How to review validation results before approving a Canvas push.
- How to write a clear build prompt that another coworker could reuse.
