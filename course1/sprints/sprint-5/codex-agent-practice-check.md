# Codex Agent Practice Check

This short check confirms the core workflow: ask in plain English, review the generated Markdown, validate locally, and stop before a Canvas push unless that push is explicitly approved.

Five questions. Four are multiple choice and one is short answer. The goal is to confirm the basic control points, not to test technical vocabulary.
