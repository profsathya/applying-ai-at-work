## Before this module is published

Both artifacts follow the Sprint 1 Candidate Log pattern: a Google Docs `/copy` link that
gives each participant their own editable copy. The documents do not exist yet, so each link
currently carries a placeholder document ID.

1. Upload each `.docx` to Google Drive and open it as a Google Doc.
2. Set link sharing to "Anyone with the link can view".
3. Copy the document ID out of the URL.
4. Replace the placeholder in the matching Markdown file, keeping the trailing `/copy`.
5. Re-run `.venv/bin/python canvas_sync/schema.py --artifact <file>` for each edited file.

Publishing with the placeholders in place would give participants two dead download links.
