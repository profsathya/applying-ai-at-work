## Link format

Both artifacts follow the Sprint 1 Candidate Log pattern: a Google Docs `/copy` link that
gives each participant their own editable copy. Keep the trailing `/copy` on both links. It
is what makes Google show a "Make a copy" prompt instead of opening the instructor's master
document, so dropping it would let participants edit the original.

## Still required before this module is published

Link sharing on both documents is still owner-only. Each one must be set to
"Anyone with the link can view" or participants will hit a request-access page instead of
the copy prompt. The document IDs above are correct; only the sharing setting is outstanding.

## If a template is regenerated

1. Upload the replacement `.docx` to Google Drive and open it as a Google Doc.
2. Set link sharing to "Anyone with the link can view".
3. Copy the document ID out of the URL.
4. Update the ID in the matching Markdown file and in the table above, keeping `/copy`.
5. Re-run `.venv/bin/python canvas_sync/schema.py --artifact <file>` for each edited file.
