# Tuple Practice Assignment

Use tuples to represent a small, stable set of values from a work context you understand.

## What to submit

Submit a short response that includes all three parts below.

1. A tuple with at least three values that belong together.
2. Two lines of code that read values from the tuple by index.
3. One line of code that unpacks the tuple into named variables.

## Example shape

```python
ticket = ("A-104", "billing", "open")

ticket_id = ticket[0]
status = ticket[2]

ticket_id, category, status = ticket
```

Do not copy this example directly. Use a work item, process, or record that makes sense to you.

## Reflection

After your code, write 3-5 sentences explaining why a tuple is a reasonable fit for this data. If a list would be better, say so and explain why.

## Submission guidance

Paste your code and reflection into the Canvas assignment text box. Keep the response concise and readable.
