# Welcome to Week 3: From Scripts to Projects

This week prepares you for the kind of work you will see in 202A.

A project is more than code. It includes structure, documentation, dependencies, tests, version history, and decisions about how people collaborate. AI can help with all of those pieces, but only if you give it enough context and review what it changes.

## What Changes This Week

In Week 1, you read and wrote small functions.

In Week 2, you modeled real-world information and tested behavior.

In Week 3, you will work inside a project:

- Files are organized into folders.
- A README explains how to use the project.
- Dependencies are installed into an environment.
- Git tracks changes.
- GitHub helps share and review work.
- Tests and debugging tools help you understand behavior.

## The Main Skill

The main skill this week is controlled change.

Before changing a project, you should be able to answer:

1. What does the project do now?
2. What change am I making?
3. Which files will probably be affected?
4. How will I test the change?
5. What would make this change risky?

These questions are useful whether you write code manually or with AI.

## Bridge To 202A

202A will focus more on implementation and workflow. This course gives you the foundation you need to enter that work with better questions:

- What does this code already do?
- What context does my copilot need?
- What tests should protect this change?
- What should I review before opening a pull request?
- What part of the system should remain human-led?

That is the handoff: not mastery of every tool, but readiness to work responsibly inside a codebase.
