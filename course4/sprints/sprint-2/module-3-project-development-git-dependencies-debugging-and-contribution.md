# Module 3: Project Development, Git, Dependencies, Debugging, and Contribution

This module moves from individual scripts to project work.

Modern code rarely lives in one file. It lives in repositories with documentation, dependencies, tests, issues, commits, and review. AI tools can help inside that workflow, but they also make it easier to create changes you do not understand.

By the end of this module, you should be able to:

1. Explain the basic structure of a Python project.
2. Use a README and AGENTS.md to clarify context for humans and AI tools.
3. Sync files through a GitHub repository.
4. Use libraries and virtual environments responsibly.
5. Read stack traces across multiple files.
6. Use a debugger to pause, inspect, and reason.
7. Analyze a starter Flask application and define requirements before prompting AI.
8. Fork a project and open a pull request for a scoped feature.

Complete these items in order:

## How To Use AI This Week

Use AI to explain project structure, summarize stack traces, propose tests, and critique a feature plan. Do not let it make a broad pull request without a narrow goal and your review.

The practical standard is simple: you should be able to explain the change before asking anyone else to review it.
