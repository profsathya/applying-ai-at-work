# Week 3 Project Reading Quiz

Use this quiz to check whether you can explain project structure, dependency management, debugging, and pull request workflow.

## Answer Key

1. A README explains what the project does and how to use or work with it.
2. A virtual environment keeps project dependencies separate.
3. True.
4. A stack trace helps trace how the program reached an error.
5. Define requirements and current project context.
6. Strong answers include project purpose, coding conventions, validation commands, safety boundaries, file ownership, or instructions for AI assistants.
7. Strong answers include summary, purpose, validation, known limitations, screenshots if relevant, or AI-use review.
8. Strong answers mention breakpoints, stepping through code, inspecting variables, or tracing values across files.
9. Strong answers connect AI pipelines to inputs, outputs, functions, errors, tests, files, databases, or validation.
10. Strong answers explain making a small, defined, testable, reviewable change.
