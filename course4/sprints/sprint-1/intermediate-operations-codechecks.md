# Intermediate Operations CodeChecks

## Purpose

Practice the operations needed for the support ticket system and classifier project.

These tasks should help you express your own coding skill. Try them without AI first. If you use AI later, use it for explanation or test case ideas.

## CodeCheck Set

Complete the CodeChecks assigned by your instructor. If a CodeCheck link is not available, write local Python functions for these prompts:

1. `count_warning_levels(tickets)` returns how many tickets have each warning level.
2. `unique_tags(tickets)` returns a set of all tags used across tickets.
3. `filter_open_tickets(tickets)` returns only tickets whose status is `"open"`.
4. `classify_ticket(text)` returns `"billing"`, `"technical"`, `"account"`, or `"unknown"` based on simple keyword rules.
5. `load_ticket_titles(path)` reads a file and returns a list of ticket titles.

## Required Reflection

Choose one function and answer:

- Why did you use a list, set, dictionary, object, or file?
- What input did you test?
- What edge case did you check?
- What would make the function unreliable?
