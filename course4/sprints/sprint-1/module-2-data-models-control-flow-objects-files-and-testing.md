# Module 2: Data Models, Control Flow, Objects, Files, and Testing

This module moves from small functions to programs that represent real situations.

You will work with objects, lists, loops, conditionals, dictionaries, sets, files, and tests. The theme is modeling. A program is not only a sequence of instructions. It is also a representation of people, events, records, rules, and decisions.

By the end of this module, you should be able to:

1. Explain how objects can represent real-world entities and behavior.
2. Use lists, sets, dictionaries, loops, and conditionals to organize and process information.
3. Read and reason about a support ticket system built from starter code.
4. Define a system before asking AI to help build or extend it.
5. Write basic tests with `pytest`.
6. Use starter training code to make classification decisions from a dataset.

## How To Use AI This Week

AI is most useful this week when you ask it to compare models:

- "What data should this object store?"
- "Which field should be a list, set, or dictionary?"
- "What test cases would reveal a bug?"

It is less useful when it writes an entire system before you define what the system should mean. Define the support ticket system first. Then ask for help.
