# Week 2 Project: Basic Classifier Training

## Purpose

Use a provided dataset and starter training code to build a basic classifier.

The goal is not to become a machine learning expert in one week. The goal is to understand how code uses features, training data, testing data, and predictions.

## Provided Materials

Your instructor will provide:

- A phone price dataset.
- Starter training code.
- Starter testing code.
- A small set of phones whose price range you need to predict.

## Your Main Decision

You must decide which feature vectors to include.

Possible features might include:

- Battery power.
- RAM.
- Storage.
- Camera quality.
- Screen size.
- Weight.
- Any other fields included in the dataset.

Do not include every feature automatically. Explain why the features you chose might help predict price.

## Required Steps

1. Open the dataset and identify the target value.
2. Manually split the data into training and testing groups using the instructor's directions.
3. Choose the features for your first model.
4. Run the provided training code.
5. Run the provided testing code.
6. Record the predictions for the required phones.
7. Change one feature choice and compare the result.
8. Write a reliability note explaining what the classifier can and cannot tell you.

## Submission

Submit:

- The features you chose and why.
- How you split train and test data.
- The predictions for the required phones.
- One comparison between two feature choices.
- One limitation of your model.
- Your AI-use note, including how you checked any AI help.

## AI Boundary

You may ask AI to explain the starter code, a dataset column, or a result. Do not let AI choose your feature vector without your reasoning. Your feature choice is the main evidence of your thinking.
