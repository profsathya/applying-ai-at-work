# Basic Operations CodeChecks

## Purpose

Practice the basic operations needed to understand the calculator and encryption project in this module.

These checks are meant to be simple. Try them without AI first. If you use AI after attempting them, use it to explain a concept or a test case, not to replace your own work.

## Required Skills

You will practice:

- Function definitions.
- Math operations.
- String operations.
- Tuples.
- Basic input and output.
- Return values.
- Simple edge cases.

## CodeCheck Set

Complete the CodeChecks assigned by your instructor. If a CodeCheck link is not available, write local Python functions for these prompts:

1. `add_tax(price, tax_rate)` returns the total price.
2. `format_receipt_item(name, price)` returns a readable receipt line.
3. `split_full_name(full_name)` returns a tuple containing first name and last name.
4. `calculator_summary(a, b)` returns a tuple containing sum, difference, product, and quotient.
5. `safe_divide(a, b)` returns a useful message when the second number is zero.

## Submission

Submit a short text entry with:

- The CodeCheck completion evidence or your local function code.
- One example input and output for two of your functions.
- One bug, edge case, or confusing moment you encountered.
- A short note on whether you used AI and how.

Do the first attempt yourself. If you use AI later, include the prompt you used and one sentence explaining how you checked the answer.
