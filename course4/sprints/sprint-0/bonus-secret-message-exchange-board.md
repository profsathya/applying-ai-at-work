# Bonus: Secret Message Exchange Board

This optional discussion lets you share an encrypted message created with your Project 1 tool.

## Initial Post

Post:

1. Your encrypted message.
2. Any public key information needed for someone else to attempt decryption.
3. One sentence describing what your command line tool did to produce the message.

Do not post private keys, passwords, personal information, or anything sensitive.

## Reply

Reply to one other participant with:

1. The decrypted message if you were able to reveal it.
2. One issue you encountered while trying to decrypt it.
3. One question about their tool or process.

## Safety Reminder

This is a learning activity. Do not use this board for real secrets.
