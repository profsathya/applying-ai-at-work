# Module 1: Code, Abstraction, Functions, and Basic Reliability

This module is your first technical foundation for reading and working with code.

The goal is not to memorize every piece of Python syntax. The goal is to understand what code is doing, why a program is organized the way it is, and how to stay in control when an AI tool produces code that looks plausible.

By the end of this module, you should be able to:

1. Explain code as instructions, information, and decisions written for a computer and for future readers.
2. Recognize algorithms, abstraction layers, functions, inputs, outputs, strings, numbers, tuples, and basic operations in small Python programs.
3. Set up a programming environment, run a Python file, and document a function clearly.
4. Read a pre-generated calculator program and explain where it succeeds, where it fails, and how to improve it.
5. Use errors and exceptions as information instead of treating them as failure.
6. Build a small command line encryption and decryption tool from a provided RSA function.

## How To Use AI This Week

You may use AI for explanation, comparison, and debugging support. For CodeChecks, try the work yourself first. The purpose of those checks is to help you build confidence in your own skill, not to prove that an AI tool can solve a small problem.

When you do use AI, ask it to explain code line by line, identify assumptions, and point out possible failure cases. Do not ask it to replace your reading.
