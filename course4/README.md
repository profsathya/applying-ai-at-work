# Science of Computing

This directory contains the local shell for course4, mapped to Canvas course ID `182` through `course4/manifests/production.json`.

This course currently has context and design files only. No module artifacts have been drafted.

## Course Shape

The repo uses `sprints/` as the Canvas module source folder, so this three-section course uses three sprint folders:

| Course section | Repo folder | Purpose |
|---|---|---|
| Section 1: Code, Abstraction, Functions, and Basic Reliability | `course4/sprints/sprint-0/` | Build first-layer code reading, basic function writing, environment setup, and reliability habits. |
| Section 2: Data Models, Control Flow, Objects, Files, and Testing | `course4/sprints/sprint-1/` | Model real-world work with objects and collections, including sets, then protect behavior with tests. |
| Section 3: Project Development, Git, Dependencies, Debugging, and Contribution | `course4/sprints/sprint-2/` | Prepare participants for project work, debugging, documentation, GitHub contribution, and 202A. |
